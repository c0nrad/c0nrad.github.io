Microgpt Review

    • Learnings / Refreshers

Recently this article popped up on the orange website: https://karpathy.github.io/2026/02/12/microgpt/. Today’s goal is comprehend the article well enough to explain any concept comfortably. A few months ago I did the first few courses of https://www.deeplearning.ai/, so most of the terms seem vaguely familiar already.

Learnings / Refreshers

  • Components: documents, tokenizer, autograd engine, neural net, adam optimizer, training loop, inference loop

  • Documents

    • In this case we’re just going to use a list of ~32000 names, each name is a “document”

  • Tokenizer

    • Split text into chunks, and assign a number value to those chunks of characters
    • https://tiktokenizer.vercel.app/
      • It looks like spaces are not their own token, instead included at the start of tokens?
      • Stuart is two tokens, “stu” and “art”
    • BOS Beginning of sequence, used at start and end
    • Vocab size of 27 (26 characters + BOS)

  • Autograd

    • The author presents an interesting Value class, which records it’s history
      • So if you did Value(2) + Value(3), the resulting value would remember it’s children (2,3)
    • Relies on the chain rule $$ \frac{d}{dx}[f(g(x))] = f\prime(g(x))g\prime(x) $$
    • So you can take the final value from the computation network, and then ask for the derivative with respect to inputs

  • Parameters

    • The weights of the model, start at random (guassigan), and are tuned
    • wte = token embeddings
    • wpe = position embeddings

  • Embeddings

    • We need to convert the vocab number into a vector
    • We also need a “position” embedding so the model knows if we’re in the middle of a word or not
